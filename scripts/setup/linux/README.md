# scripts/setup/linux/ — OPCJONALNE

Odpowiedniki bash skryptów z `scripts/setup/windows/`. Środowiskiem głównym projektu
jest Windows + PowerShell, dlatego wersje linuksowe są opcjonalne i nie są wymagane
do przeprowadzenia pomiarów.

Jeśli powstaną, mają odwzorować 1:1 zachowanie i idempotencję wersji windowsowych.

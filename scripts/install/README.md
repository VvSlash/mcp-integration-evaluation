# scripts/install/ — katalog zarezerwowany

Kanoniczną lokalizacją instalatorów jest `scripts/setup/windows/` — tam znajdują się
m.in. `download_third_party_mcp_servers.ps1` (pobieranie serwerów MCP innych autorów)
i `install_blender.ps1` (instalacja Blendera). Jedna ścieżka zamiast duplikatów.

Katalog pozostaje na ewentualne wspólne (wieloplatformowe) helpery instalacyjne.
